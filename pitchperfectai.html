PitchPerfectAI

Turns GitHub repositories and project documents into compelling pitch decks — generated by AI, exported to PowerPoint.

Overview

PitchPerfectAI is a live platform that reads a founder's GitHub project or documents and writes the pitch deck for them. I built the whole product myself — frontend, authentication, database and the AI model-selection logic that decides how each deck is generated.

How it works

  1. 01

    Connect

    Sign in with GitHub OAuth and pick a repository or upload documents.

  2. 02

    Parse

    The project is parsed to pull out the product, features and audience.

  3. 03

    Generate

    Gemini AI writes the deck content, within the user's token allowance.

  4. 04

    Export

    The finished deck is exported as a PowerPoint file.

What I built

  • GitHub project and document parsing that extracts what a product does and who it serves.
  • AI-generated deck content with model-selection logic built on Gemini AI.
  • PowerPoint export so decks leave the platform ready to present.
  • GitHub OAuth sign-in and token-based usage controls to meter generation.
  • A separate waitlist app with a landing page, admin dashboard, user status tracking, CSV export and an email campaign composer with templates and personalisation variables.
