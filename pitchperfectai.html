PitchPerfectAI

Turns project descriptions, documents and GitHub repositories into investor-ready pitch decks — generated by AI, exported to PowerPoint.

Type
AI · SaaS platform
Role
Solo — built end to end
Visit pitchperfectai.org ↗View code ↗

Overview

PitchPerfectAI reads what a founder is building — a written description, uploaded documents or a GitHub repository — and writes a 13-slide investor pitch deck from it. I built the whole product myself: frontend, authentication, database and the AI model-selection logic behind every deck.

15Demo users

How it works

  1. 01

    Describe

    Sign in with GitHub, then describe the project, upload documents or connect a repository.

  2. 02

    Analyse

    The input is parsed for the product, the problem it solves and its audience.

  3. 03

    Generate

    Each part of the deck is written in its own AI stage, falling back to another model if one fails.

  4. 04

    Export

    Refine with Pitchy, then download as PowerPoint, Word or PDF.

What I built

  • Three ways in: a project description, uploaded documents (TXT, MD, DOC, DOCX, PDF) or a GitHub repository analysed for a quick start.
  • A 13-slide investor deck covering the problem, solution, market opportunity, business model and more, in investor, product-demo or partnership styles.
  • Model-selection logic that generates each section in its own stage and falls back across models (Mistral, Zephyr, Phi-3, FLAN-T5) when one is unavailable. Content generation started on Gemini AI.
  • Pitchy, an in-app assistant that researches and rewrites deck content on request.
  • Export to PowerPoint (PPTX), Word (DOCX) and PDF, plus saved projects to manage multiple decks.
  • GitHub OAuth sign-in, token-based usage limits across Free, Pro and Enterprise tiers, and an admin dashboard.
  • A separate waitlist app with a landing page, signup management, CSV export and an email campaign composer.
