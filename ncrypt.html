NCrypt

Share files with end-to-end encryption. Files are encrypted in the browser before they ever leave your device.

Type
Security · Encrypted file transfer
Role
Full stack — frontend, API & admin
Live demo ↗

Overview

NCrypt is a client-side encrypted file transfer app. Upload a file, get a short share ID, and send it to anyone — no accounts needed. Because encryption happens in the browser, the server only ever stores ciphertext.

AES-GCM256-bit encryption
100kPBKDF2 iterations
8-charShare IDs

How it works

  1. 01

    Encrypt

    The file is encrypted in a Web Worker with a key derived from your passphrase.

  2. 02

    Upload

    Only the ciphertext is sent to the Flask API and stored.

  3. 03

    Share

    You receive an 8-character share ID to send to the recipient.

  4. 04

    Decrypt

    The recipient finds the file by ID and decrypts it locally in their browser.

What I built

  • Browser-side AES-GCM encryption using the Web Crypto API, with keys derived through PBKDF2 (SHA-256, 100,000 iterations).
  • Encryption running in a Web Worker so large files don't freeze the interface.
  • Unique 8-character share IDs for search, retrieval and download.
  • An admin dashboard for visitor statistics, upload and download tracking and stored-file metadata, secured with Firebase Authentication and token verification on the backend.
  • Drag-and-drop uploads with progress tracking, file-type validation, size limits and optional ClamAV malware scanning.
  • Pluggable storage backends and deployment to Netlify (frontend) and Railway (backend).
