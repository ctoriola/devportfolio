Orderly

Overview

Orderly is a queue-management system for any location with a line. Each location gets its own QR codes: one to join the queue and one to check status. Administrators manage locations and queues from a dashboard.

QRJoin & status codes
2Admin tiers
AWSDynamoDB + S3

How it works

  1. 01

    Scan

    A visitor scans the location's join QR code.

  2. 02

    Join

    They join the queue and get a position and receipt.

  3. 03

    Track

    The status page shows their place and how many are waiting.

  4. 04

    Manage

    Admins move the queue along from the dashboard.

What I built

  • QR-based location access — every location generates a join code and a status code.
  • Queue workflows to join, check position and leave, with waiting counts and estimated wait.
  • Downloadable receipts for each place in the queue.
  • Admin controls to create locations, plus a super-admin tier to create and edit administrators.
  • DynamoDB for queue data and S3 for QR code storage, falling back to local storage when AWS isn't configured.
